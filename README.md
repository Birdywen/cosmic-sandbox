# Cosmic Sandbox · 交互式宇宙沙盘模拟器

基于 **Next.js 15 + Canvas API** 的赛博朋克宇宙模拟器。真实牛顿引力、碰撞合并、时空扭曲可视化。

## 特性

1. **天体放置** — 画布点击放置星球，按住拖拽设定初速度方向与大小（弹弓式），松手发射。
2. **引力模拟** — 每对天体施加真实牛顿引力 `F = G·m₁·m₂/r²`，半隐式欧拉积分，形成自然/椭圆轨道。
3. **碰撞合并** — 距离小于半径之和即合并，守恒质量与动量（`v=(m₁v₁+m₂v₂)/(m₁+m₂)`），触发粒子爆炸。
4. **时空扭曲** — 大质量天体使 Canvas 网格顶点向质心偏移，模拟引力透镜/时空弯曲。
5. **轨迹残影** — 每个天体保留过去 N 帧轨迹，亮度/宽度由尾到头渐隐，形成霓虹拖尾。
6. **控制面板** — 调节引力常数 G、时间步长 dt、质量范围、轨迹长度、粒子数量，支持暂停/重置。
7. **视觉风格** — 纯黑背景 + 青/品红霓虹配色 + 发光 bloom，极简科幻。

## 技术栈

- Next.js 15 (App Router) + React 19 + TypeScript
- 原生 Canvas 2D API（无 Three.js 依赖，轻量高性能）
- Tailwind CSS

## 结构

```
app/
  page.tsx            # 入口，渲染 CosmicSandbox
  layout.tsx          # 根布局 / metadata
  globals.css         # 全局样式 + 霓虹滑块样式
components/
  cosmic-sandbox.tsx  # 画布 + 指针交互 + 控制面板 + 渲染循环
lib/
  physics.ts          # 引力积分 / 碰撞合并 / 粒子
  render.ts           # 时空网格 / 天体 bloom / 拖尾 / 预览
```

## 本地运行

```bash
npm install
npm run dev
```

打开 http://localhost:3000 。

## 操作

| 动作 | 效果 |
| --- | --- |
| 点击画布 | 放置天体（质量随机于设定范围内） |
| 按住拖拽 | 设定初速度方向与大小（反向弹弓） |
| 松开 | 天体按初速度开始运动 |
| 双方距离 < 半径和 | 合并 + 粒子爆炸 |

## 物理模型

- 引力：`a_i = Σ_j G·m_j·(r_j - r_i) / (|r|² + ε²)^{3/2}`
- 积分：半隐式欧拉，每帧 2 次子步进
  - 软化项 ε 避免近距离奇点
- 合并：完全非弹性碰撞，动量守恒，半径 ∝ mass^(1/3)
